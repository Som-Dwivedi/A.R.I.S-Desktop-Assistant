# A.R.I.S. (Advanced Research & Integration System)

A desktop-based personal AI assistant and automation suite powered by local Large Language Models (Ollama / Llama-3) and an asynchronous CustomTkinter HUD interface.

## 🚀 Key Features
- **Local Neural Inference:** Integrated with local LLMs (Llama-3 via Ollama REST API) ensuring offline-first execution and local data privacy.
- **Context-Aware Memory Pipeline:** Dynamic memory recall engine pairing JSON-based persistent entity storage with keyword context injection.
- **System Automation Suite:** Native OS hooks for application lifecycles, real-time query parsing, and command execution pipelines.
- **Custom Cyberpunk HUD:** Modern multi-panel CustomTkinter interface with system telemetry and real-time conversation stream.

## 🛠️ Tech Stack
- **Language:** Python 3.10+
- **GUI:** CustomTkinter
- **Inference Core:** Ollama (Llama-3)
- **Networking & Automation:** Requests, Subprocess, Webbrowser
